# IntroToRecursion_Factorial

Implementing Recursion to Provide a Product
_____________________________________________________________

Using recursion, create a program that allows a user to enter five numbers. 
The program will then provide the product of all five numbers using recursive methods.

We will use a classic problem for recursion of the factorial of an integer.
The factorial of any given integer — call it n — is the product of all the integers from 1 to n.

The recursive way to look at the factorial problem is to realize that the factorial for any given number n is equal to n times the factorial of n–1, provided that n is greater than 1. If n is 1, the factorial of n is 1.
